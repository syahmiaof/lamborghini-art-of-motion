## Motion beats and fallback

- **Threshold:** one optional short frame sequence. On mobile or reduced motion, show the strongest approved still with a brief light reveal. The skip link is present from first paint.
- **Presence → Velocity:** a single hard directional transition makes the pacing change perceptible; it must not require the user to scroll through blank pin distance.
- **Velocity → Engineering:** the last metric line becomes the first annotation line. If no technically accurate detail image is cleared, use the verified data as editorial typography rather than pointing to an incorrect component.
- **Interior → Showroom:** movement decelerates. The model index is a deliberate user-controlled interaction, not an automatic scroll carousel.
- **Configure → Finale:** carry the visitor's supported selected look into a summary; if configuration is reduced to a gallery, the finale uses the approved hero still instead.

## Narrative checkpoints

- **First 5 seconds:** independent concept and featured model are understandable; nav and skip are available.
- **Midpoint:** visitor has learned a real performance fact and a real engineering fact, not just watched transitions.
- **Last chapter:** visitor can identify the project creator and follow an honest portfolio CTA.

## Story resilience

Direct links to chapters must land on readable content without running the intro. Backward scroll reverses scrubbed sequences cleanly. Refresh at an anchor or browser history restore must not replay a blocking overlay. If motion is unavailable, all chapters become a coherent editorial long page.
