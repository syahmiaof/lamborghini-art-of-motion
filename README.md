# LAMBORGHINI — THE ART OF MOTION

Independent frontend concept for a cinematic automotive portfolio experience. This is a planning repository at present; no application or media assets have been added.

**Project status (11 October 2026):** Phase 1–3 planning packet and a runnable React/Vite development scaffold are in place. The cinematic homepage is not built yet. Asset rights and final photo selection are open production gates.

## Run the scaffold

```bash
npm install
npm run dev
```

`npm run lint` and `npm run build` are the current verification gates. The visible page is a typographic development frame and chapter index, with no vehicle media or implied configurator functionality.
